# OpenStreetMap data

`mauritius-261101.osm.pbf`: the Geofabrik extract of Mauritius dated 2026-11-01 (https://download.geofabrik.de/africa/mauritius.html). It covers Mauritius and the outer islands; the map script crops it to the main island.

Map data © OpenStreetMap contributors, available under the Open Database Licence (ODbL): https://www.openstreetmap.org/copyright. The game and the README must show this credit.

To refresh: download a newer `mauritius-latest.osm.pbf`, save it here with its date in the name, and rerun the map script.
